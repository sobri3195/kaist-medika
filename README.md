# Kai'st Medika Ecommerce (React + Vite)

Website ecommerce modern dan premium untuk brand **Kai'st Medika**.

## Menjalankan project

```bash
npm install
npm run dev
```

## Build production

```bash
npm run build
npm run preview
```
